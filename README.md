## MindBloom
a cozy little corner of the internet that might help you.
not a therapy app. not a self-help lecture. just a vibe.

## what even is this?
mood check-ins. AI that doesn't gaslight you. a calm corner for when your brain is a browser with 47 tabs open. anonymous community for when you need to rant but not to anyone who knows you.
built for the chronically overwhelmed college student. so, everyone.

## stack?

react + vite
tailwind css
framer motion (smoother than your sleep schedule)
gemini api
firebase
react router


## how to run?
bashgit clone https://github.com/vanshikaprakash/MindBloom.git
cd MindBloom
npm install
npm run dev
runs on http://localhost:5173
create a .env file, add your VITE_GEMINI_API_KEY, and boom — the AI actually talks back.


## 💡 features

mood check-in → pick how you feel, rate the chaos, get AI suggestions that aren't insulting
calm corner → books, lo-fi playlists, pomodoro timer, wellness blogs. your 2am survival kit
anonymous community → say the thing you can't say anywhere else. no usernames, no judgment
AI chat companion → emotionally intelligent, never annoying, available at 3am unlike everyone else
focus mode → pomodoro + ambient themes + task list. pretend you're in a rainy café
dashboard → mood streaks, weekly graphs, affirmations. watch yourself actually cope
emergency support → breathing exercises, grounding techniques, helplines. just in case


## why?
because college is a lot. like, a lot a lot.
and sometimes you just need something that gets it without making it weird.
